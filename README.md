# Jogos de Dados

Este é um simples jogo de dados desenvolvido em C# para ser jogado no console. 
O jogo consiste em uma disputa entre um jogador e o computador, 
onde ambos rolam um dado para avançar no tabuleiro até alcançar a linha de chegada.

## Como Jogar

1. Execute o programa.
2. O jogador pressiona ENTER para rolar o dado.
3. Dependendo do resultado, o jogador avança no tabuleiro.
4. O computador então rola o dado automaticamente.
5. Existem casas com efeitos especiais:
   - **Bônus**: Avança 3 casas (posições 5, 10, 15, 25).
   - **Penalidade**: Retrocede 2 casas (posições 7, 13, 20).
6. O primeiro a atingir ou ultrapassar a posição 30 vence.
7. Após o término, o jogador pode optar por reiniciar ou encerrar o jogo.

## Requisitos

- .NET SDK instalado

## Como Executar

1. Abra um terminal na pasta do projeto.
2. Compile e execute com o comando:
   ```sh
   dotnet run
   ```
